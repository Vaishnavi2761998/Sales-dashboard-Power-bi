# Sales Analytics Dashboard | Power BI

An interactive Power BI Sales Analytics Dashboard for analysing mobile-phone sales, transactions, customer ratings, payment methods, locations, and time-based performance.

## Project file

- `Sales dashboard.pbix`

Open the `.pbix` file using Power BI Desktop.

## Dashboard features

- Total Sales, Total Quantity, Total Transactions, and Average Price KPIs
- Filters for Mobile Model, Payment Method, Brand, and Year
- Month and date-level sales analysis
- City-wise sales map
- Sales by mobile model and day name
- Customer rating analysis
- Payment method distribution
- Brand-level sales and transaction summary
- Month-to-date reporting
- Same-period-last-year comparisons by year, quarter, and month

## MTD Report

The MTD (Month-to-Date) report tracks sales progress throughout the selected month, helping monitor daily performance against total sales.

![MTD Report](images/mtd-report.png)

## Same Period Last Year Report

This page compares current sales with the same period in the previous year. It includes yearly, quarterly, and monthly comparisons.

![Same Period Last Year Report](images/same-period-last-year.png)

## Tools Used

- Power BI Desktop
- DAX
- Power Query
- Data Visualization

## How to Use

1. Download or clone this repository.
2. Open `Sales dashboard.pbix` in Power BI Desktop.
3. Refresh the data if required.
4. Use the filters and navigation buttons to explore sales performance.
